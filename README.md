# C&C 나폴레오닉 솔로 · 온라인 2인

**Commands & Colors: Napoleonics**(GMT Games, 리처드 보그 디자인) 기본판 시나리오 15개와 확장1 스페인군 18개, 확장2 러시아군 20개, 확장3 오스트리아군 20개, 확장4 프로이센군 20개를 웹 브라우저에서 플레이하는 비공식 팬 도구입니다. 한 파일(`index.html`)로 동작하고, 솔로는 서버나 설치가 필요 없습니다.

- **솔로 모드**: 리처드 보그의 *Power of Three* 솔로 규칙 (3장 손패, 1장 남기고 2장 받기, 정찰·선제 공격·보급 부족·방진 예외)
- **AI 대전**: 진영을 고르면 컴퓨터가 반대편을 맡는다. 2인 규칙(손패 = 지휘카드 수, 선제 공격·방진표)으로 진행하고, AI는 카드 선택·명령·이동·공격 대상과 방진·반격·후퇴 칸 같은 방어 결정을 기대값으로 고른다. AI 차례에는 1초 안팎씩 쉬며 움직임을 보여 준다.
- **온라인 2인**: Firebase Realtime Database로 각자 자기 기기에서 대전. 방 코드·초대 링크, 내 손패만 보기, 상대 화면에 이동·전투 애니메이션과 주사위 중계, 방어측 결정(방진·반격·후퇴 칸 등)은 방어하는 사람 화면에서, 채팅, 새로고침해도 자동 재접속. 규칙은 원래 2인 규칙(시나리오 지휘카드 수만큼 손패, 상대 턴의 선제 공격 반응, 방진표 카드)
- 육각 지도, 구역별 명령, 이동 경로, 조준선·사거리, 주사위 계산 내역, 명중·후퇴·깃발 무시, 리더 피해, 반격·위치확보·돌파·추가공격, 연합전투, 퇴각 및 재편성, 승리깃발과 목표 칸
- 이동·근접 돌격·머스킷 일제사격·포탄 애니메이션과 효과음(Web Audio로 합성, 외부 파일 없음). 화면 위 버튼으로 끄기 가능
- 되돌리기(Ctrl+Z), 브라우저 자동 저장, 지형·유닛 편집 모드
- 한국어 규칙 요약, 국가별 유닛표, 지형표, 지휘카드 70장 목록

## 바로 실행

`index.html`을 더블클릭해 브라우저로 열면 됩니다. (글꼴만 Google Fonts에서 받고, 인터넷이 없으면 시스템 글꼴로 표시됩니다.)

## GitHub에 올리고 GitHub Pages로 공개하기

1. GitHub에서 새 저장소를 만듭니다 (예: `cnc-napoleonics-solo`). README 추가는 체크하지 않습니다.
2. 이 폴더에서:

   ```bash
   git init
   git add .
   git commit -m "C&C 나폴레오닉 솔로·2인 첫 버전"
   git branch -M main
   git remote add origin https://github.com/<내 아이디>/cnc-napoleonics-solo.git
   git push -u origin main
   ```

3. 저장소 **Settings → Pages**에서 *Source*를 **Deploy from a branch**, 브랜치 **main**, 폴더 **/(root)** 로 저장합니다.
4. 1~2분 뒤 `https://<내 아이디>.github.io/cnc-napoleonics-solo/` 에서 열립니다.

## 온라인 대전 설정 (Firebase, 무료 요금제로 충분)

Firebase 설정이 없으면 솔로만 켜지고, 아래를 한 번 해 두면 **새 게임 → 온라인 2인**이 열립니다. 10분쯤 걸립니다.

1. **프로젝트 만들기** — <https://console.firebase.google.com> 에서 *프로젝트 추가*. 이름은 아무거나(예: `my-cnc`), Google 애널리틱스는 꺼도 됩니다.
2. **웹 앱 등록** — 프로젝트 개요 화면의 `</>` (웹) 아이콘 → 앱 닉네임 입력 → *앱 등록*. 호스팅 설정은 체크하지 않습니다. 화면에 나오는 `firebaseConfig = { ... }` 값을 잠시 둡니다.
3. **익명 로그인 켜기** — 왼쪽 메뉴 *빌드 → Authentication → 시작하기 → Sign-in method* 에서 **익명(Anonymous)** 을 사용 설정합니다. 방 자리를 사람별로 구분하는 데 씁니다.
4. **Realtime Database 만들기** — *빌드 → Realtime Database → 데이터베이스 만들기*. 위치는 한국에서 가장 가까운 **싱가포르(asia-southeast1)**, 보안 규칙은 *잠금 모드*로 시작합니다.
5. **보안 규칙 넣기** — Realtime Database의 *규칙* 탭에 이 저장소의 `database.rules.json` 내용을 통째로 붙여 넣고 *게시*합니다. 로그인한 사람만 읽을 수 있고, 각 방은 자리를 잡은 두 사람만 쓸 수 있게 막습니다.
6. **승인된 도메인 추가** — *Authentication → 설정 → 승인된 도메인* 에 `<내 아이디>.github.io` 를 추가합니다.
7. **설정값 넣기** — *프로젝트 설정(톱니바퀴) → 일반 → 내 앱* 의 구성 값을 `firebase-config.js` 에 붙여 넣습니다. 4번을 한 뒤라야 `databaseURL` 이 들어 있습니다. 커밋하고 푸시하면 1~2분 뒤 GitHub Pages에 반영됩니다.

```js
window.FIREBASE_CONFIG = {
  apiKey: "AIza...",
  authDomain: "my-cnc.firebaseapp.com",
  databaseURL: "https://my-cnc-default-rtdb.asia-southeast1.firebasedatabase.app",
  projectId: "my-cnc",
  appId: "1:1234567890:web:abcdef"
};
```

`apiKey` 같은 웹 구성 값은 공개 저장소에 올라가도 되는 값입니다(브라우저에 그대로 내려가는 값). 데이터 보호는 5번의 보안 규칙이 합니다.

**대전하는 법** — 방장이 *새 게임 → 온라인 2인*에서 진영을 고르고 시나리오를 누르면 방 코드가 생깁니다. *초대 링크 복사*로 상대에게 보내면, 상대는 링크를 열고 *참가*만 누르면 됩니다.

**사용량** — 상태 한 번이 약 20KB이고 행동할 때마다 두 사람에게 내려가므로, 한 판(60턴 정도)에 수십 MB입니다. 무료(Spark) 요금제의 월 10GB 다운로드로 한 달에 100판 넘게 할 수 있습니다. 끝난 방은 Realtime Database 화면에서 `rooms` 아래 항목을 지우면 됩니다.

**한계** — 주사위는 차례인 쪽 브라우저에서 굴리고, 손패를 포함한 상태가 방에 통째로 저장됩니다. 개발자 도구로 보면 상대 손패가 보이므로 친선 대전용입니다.

### 온라인 기능을 Firebase 없이 시험하기

같은 브라우저에서 창 두 개로 확인할 수 있습니다. 로컬 웹 서버로 연 뒤 주소 끝에 `?net=local` 을 붙여 두 창에서 엽니다 (예: `python3 -m http.server` → `http://localhost:8000/?net=local`). 한 창에서 방을 만들고 다른 창에서 코드로 참가합니다.

## 고치는 법

소스는 `src/`에 나뉘어 있고, `index.html`은 그걸 합친 결과물입니다. `src/`를 고친 뒤 다시 합칩니다 (Node.js 18 이상, 추가 패키지 없음).

```bash
node build.mjs
```

| 파일 | 내용 |
|---|---|
| `src/data.js` | 유닛 능력치, 지형, 지휘카드 70장, 기본판 시나리오 15개 배치 |
| `src/scen_ex.js` | 확장1 스페인군 18개, 확장2 러시아군 20개 시나리오 |
| `src/scen_ex2.js` | 확장3 오스트리아군 20개, 확장4 프로이센군 20개 시나리오 |
| `src/engine.js` | 육각 좌표, 턴·카드·명령 규칙, 이동, 조준선, 주사위 계산 |
| `src/flow.js` | 전투 진행(방진, 반격, 후퇴, 돌파, 리더), 선행 카드 |
| `src/fx.js` | 효과음 합성과 지도 애니메이션 |
| `src/net.js` | 온라인 2인: Firebase 연결, 방, 상태 동기화, 상대 결정 묻기, 애니메이션 중계 |
| `firebase-config.js` | Firebase 웹 앱 설정 (직접 채움) |
| `database.rules.json` | Realtime Database 보안 규칙 |
| `src/ai.js` | AI 대전: 카드·명령·이동·전투·방어 결정을 고르는 휴리스틱 |
| `src/ui.js` | 지도·패널 그리기, 클릭 처리, 편집 모드 |
| `src/shell.html` | 화면 틀과 스타일 |
| `src/rules.html`, `src/guide.html` | 규칙 설명, 진행법 |

### 시나리오 배치 표기

`src/data.js`의 각 시나리오에서 좌표는 `행,열`입니다. 0행이 위쪽(영국군 끝열), 8행이 아래쪽(프랑스군 끝열)이고, 짝수 행은 13칸, 홀수 행은 12칸(반 칸 오른쪽)입니다. 유닛은 `LN1,4`처럼 종류+좌표, 앞에 `p`는 포르투갈, `a`는 동맹(네덜란드·나사우·하노버)입니다. 책의 지도 그림을 칸 단위로 옮긴 것이라 다른 칸이 있으면 여기서 고치거나, 게임 안의 **편집**에서 고친 뒤 "기본값으로 저장"을 쓰면 됩니다.

## 알려진 한계

- 기본판 70장 덱을 씁니다. 확장1~4 시나리오와 규칙(게릴라, 창기병, 어머니 러시아, 코사크, 대규모 대대, 강철 같은 의지, 교회·호수·습지·성·4면 보루, 새 목표 종류)은 들어 있고, 확장5(장군·원수·전술가 카드)는 없습니다.
- 확장 시나리오 지도는 한국어 설명서의 그림을 칸 단위로 옮긴 것입니다. 비토리아의 첫 턴 정하기는 영국 먼저로 단순화했고, 어머니 러시아의 코사크는 러시아 끝 열의 적과 붙지 않은 빈칸에 놓습니다.
- 워털루의 "충동적인 영국 기병"은 돌파 강제만 자동이고, 프랑스 쪽으로 한 칸 더 가는 칸은 직접 고릅니다.

## 저작권 안내

Commands & Colors 및 Commands & Colors: Napoleonics는 GMT Games와 Richard Borg의 상표·저작물입니다. 이 저장소는 게임을 가진 사람이 혼자 또는 둘이 연습할 수 있게 만든 비공식 도구이며, 규칙서·시나리오북·카드 원본 파일은 포함하지 않습니다. 저장소를 공개할 때는 이 점을 유지해 주세요.
